## What I've built

- **[AI Resume Builder PRO](https://github.com/bitmorph2347/AI-Resume-Genarator-)** — full-stack resume generator with a live split-screen preview, four ATS-friendly templates, Gemini-powered bullet polishing, PDF export and JWT login.
- **[Stock Price Prediction](https://github.com/bitmorph2347/Stock-Price-Prediction-ML)** — Streamlit app that pulls market data, engineers features and compares Linear Regression, Decision Tree and Random Forest models with a chronological train/test split.
- **[Cosmic Chronicles](https://github.com/bitmorph2347/cosmic-chronicles)** — zero-dependency web app that reveals your zodiac sign and a random horoscope from your date of birth.
- **[Mathstronaut](https://github.com/bitmorph2347/Mathstronaut-Unity-Game-)** — space-themed Unity math game for kids.
- **[wumpus](https://github.com/bitmorph2347/wumpus)** — a JavaScript take on the classic Hunt the Wumpus game.
